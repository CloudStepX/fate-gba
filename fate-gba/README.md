# FATE – Game Boy Advance

A Game Boy Advance emulator that runs entirely in your browser. Single file, no dependencies, no server code.

**Live:** `https://<your-username>.github.io/<repo-name>/`

## Use it
1. Open the page (desktop or mobile browser).
2. Load a GBA ROM **you own** from your device.
3. Play. Saves and settings are stored in your browser (localStorage/IndexedDB).

No ROMs or BIOS files are included in this repository.

## Android
`FATE-GBA.apk` is a thin WebView wrapper around the same `index.html`.

## Host it yourself
- GitHub Pages: Settings → Pages → Source: **GitHub Actions** (or "Deploy from a branch" → `main` / root).
- Or just open `index.html` in a modern browser / serve any static folder.
